# Validate Plan Command

Execute the validate-plan skill to:

1. Load and parse the current implementation plan
2. Review all code changes for quality and correctness
3. Perform gap analysis between plan and implementation
4. Update the roadmap with completed items
5. Identify next priority tasks
6. Commit changes with comprehensive message

If an argument is provided, focus validation on that specific phase or feature.
